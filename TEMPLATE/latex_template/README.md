# OCAD LaTeX template (test version, mock data)

Same visual identity as `TEMPLATE/ocad_style.css`, built with LaTeX.
Everything in `charts/`, `data/` and `main.tex` is MOCK content for testing.

## Build
Requires XeLaTeX (TeX Live or MiKTeX) with the packages tcolorbox, tikz, pgfplotstable,
titlesec, fancyhdr, colortbl, tabularx, longtable, microtype, needspace, nowidow, lastpage, enumitem.

    latexmk -xelatex main.tex        (or build.sh / build.bat)

Output: `main.pdf` (A4, full ivory background on every page).

## Files
- `ocad.sty` : the style (palette, fonts, headers/footers, headings, tables, charts, boxes, cover).
- `main.tex` : example report using every component, in the OCAD section order (Cover, Executive Summary, A to G).
- `charts/` : mock PNG charts and a mock logo, generated by `make_mock_images.py`.
- `data/financials.csv` : mock data loaded into a styled table with `\ocadcsvtable`.

## Fonts
Body: Liberation Serif. Tables, captions, headers: Liberation Sans. Display titles: TeX Gyre Pagella by default
(falls back to Liberation Serif). To use Lora (the HTML template face), install a STATIC Lora
SemiBold and load `\usepackage[lora]{ocad}`. Variable-font builds of Lora do not embed reliably in XeLaTeX.

## Components
- Cover: `\ocadcoversetup{company=, ticker=, exchange=, series=, date=, analyst=, price=, pricenote=, chart=, chartcaption=, logo=}` then `\makeocadcover`. Leave `logo` out to omit the logo.
- Running footer id: `\ocadSetReportID{...}`. The header right label follows the current `\section`.
- Sections: `\section{A. About the Business}` (new page, unnumbered), `\subsection`, `\subsubsection`.
- Provenance tags: `\Sourced`, `\Reasoned`, `\Calculated`, or `\ocadtag{Any}`.
- Table: `\begin{ocadtable}{Caption}{L R R}` ... `\ocadtablehead{\ocadH{A}&\ocadH{B}&\ocadH{C}}`, rows end with `\ocadhr`, then `\ocadtablenote{...}`. Column types: L (left), R (right), C (centre), plus normal p{} and l, r.
- Long table with repeated header: see section F of `main.tex` (`\ocadlongtablesetup`, `\endfirsthead`, `\endhead`).
- CSV table: `\ocadcsvtable{Caption}{data/file.csv}`.
- Chart: `\ocadchart{file}{Title}{Caption}`; two side by side: `\ocadchartpair{f1}{t1}{c1}{f2}{t2}{c2}`.
- Callout: `\begin{ocadcallout}{Title}...\end{ocadcallout}`.
- Framework grid: `\begin{ocadframework}\fwrow{Label}{Text}...\end{ocadframework}`.
- Flow diagram: `\begin{ocadflow}{3}\flowbox{Title}{Body}...\end{ocadflow}` (argument = boxes per row).
- Footnote block: `\begin{ocadfootnotes}...\end{ocadfootnotes}`; disclaimer: `\begin{ocaddisclaimer}...\end{ocaddisclaimer}`.
- Sources: `\ocadsourcegroup{Primary Sources}` and `\ocadsource{Org}{Title}{Date}{URL}{Information}` (URLs are printed as plain text, not links).
- Lede paragraph `\ocadlede{...}`; small-caps label `\ocadlabel{...}`.

## Rules carried over from the OCAD design system
No em dashes, hash signs, asterisks or arrows in text. Numbers right aligned, text left aligned.
Do not mention how the report was produced anywhere except the standard disclaimer.
